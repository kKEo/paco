# Child profiles

A profile represents one child. Schedules and app rules always belong to a profile.

## Create a profile

1. Open **Profiles** and click **Add Profile**.
2. Enter the child's name and click **Create**.

The first profile you create becomes the active profile on your Mac automatically.

Each profile card shows how many schedules and app rules it has.

## The active profile

The card marked **Active on this device** is the profile whose rules apply to the Mac you are using. Click **Set as Active** on another card to switch.

This matters mainly when you use PaCo on a single Mac. On a paired child's Mac, see the note below.

{% hint style="warning" %}
**Several children, several Macs.** In this version a child's Mac receives the rules of all profiles and enforces all of them. If two children have different rules on different Macs, both Macs get both sets. Until per-device profiles arrive, keep one profile per family, or use rules that suit every child. See [Known limitations](../developer-guide/known-limitations.md).
{% endhint %}

## Delete a profile

Right-click the profile card and choose **Delete**. The profile's schedules and app rules are deleted too, and the change is sent to paired Macs.
