# Book diagrams

The SVG graphics in `docs/gitbook/.gitbook/assets/` are generated by these scripts so they share one palette, font stack and icon set.

| File | Produces |
|---|---|
| `svgkit.py` | Shared helpers: palette, primitives, icons (shield, laptop, lock, …) |
| `ug.py` | User Guide graphics, `ug-*.svg` |
| `dg.py` | Developer Guide graphics, `dg-*.svg` |

Regenerate after editing:

```bash
python3 docs/diagrams/ug.py docs/gitbook/.gitbook/assets
python3 docs/diagrams/dg.py docs/gitbook/.gitbook/assets
```

Preview a render on macOS without a browser:

```bash
qlmanage -t -s 1520 -o /tmp docs/gitbook/.gitbook/assets/ug-pairing.svg
```

Each graphic draws its own white rounded background, so it stays readable in GitBook's dark theme. Keep text inside its boxes: at 12 px, SF averages about 6.5 px per character and the monospace font about 7 px.
